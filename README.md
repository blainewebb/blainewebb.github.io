# Kids' games

The public home of the kids' learning games, served by GitHub Pages at
https://blainewebb.github.io/innovativeltc/<game>/

The games live under `innovativeltc/` so their web addresses, home screen
icons and saved progress stay the same as when they were served from the
`innovativeltc` repository, which is now private. Edit and push the games
here; nothing in the private repository is published any more.

Only games belong in this repository. It is public.
